# MEGA / Аудиогид выставки

Мобильная платформа ITMO MEGA BATTLE: непрерывный звуковой фон, аудиоистории и встроенный QR-сканер. Посетитель открывает стартовый QR, включает звук и сканирует экспонаты внутри плеера.

## Локальный запуск

Нужен Node.js 18 или новее. Зависимостей для запуска нет.

```sh
npm start
```

Плеер: http://localhost:4173/?start=1

QR-коды и печать: http://localhost:4173/qr.html

Другой порт: `PORT=3000 npm start`.

## Проверка

```sh
npm test
```

18 проверок плеера и обработки QR. Подробности браузерной проверки и её ограничения — в [QA.md](QA.md).

## Публикация и QR

Для камеры телефона нужен HTTPS. Можно запустить Node-сервер за HTTPS-прокси или разместить содержимое `dist/` на статическом HTTPS-хостинге в корне сайта. Сервер поддерживает HTTP Range для аудио в Safari.

По умолчанию стартовый QR генерируется на странице `qr.html` для текущего адреса платформы. Если страницу кодов открывают локально, а посетители должны переходить на отдельный публичный адрес, укажите его в `dist/runtime.js` и `dist/runtime.json`:

```js
window.GUIDE_RUNTIME = {
  publicOrigin: 'https://guide.example.org',
  testMode: false,
  legacyOrigins: []
};
```

В JSON-файле укажите тот же объект без `window.GUIDE_RUNTIME =` и без точки с запятой.

Коды экспонатов содержат `MEGA:1`–`MEGA:4`, поэтому не зависят от домена и предназначены для сканера внутри плеера. На странице есть обычные ссылки на точки, скачивание PNG и печать. Стартовый QR скачивается оттуда после настройки адреса — временный адрес не включён в репозиторий.

## Аудио и материалы

В `dist/content.js` задаются названия, подписи и пути к аудио. Четыре синтезированные демозаписи находятся в `dist/audio/01.m4a`–`04.m4a`. Замените их своими MP3/M4A, обновите пути и установите `demo: false`.

`dist/audio/ambient.wav` — отдельный зацикленный тестовый фон. При сканировании меняется рассказ, а фон продолжает играть. Пауза останавливает оба звуковых слоя.

Шрифты и библиотеки QR включены локально; лицензии лежат рядом с файлами. Демоистории загружаются в память для последующих переключений. Полный офлайн-запуск после закрытия страницы не реализован.

## Структура

- `dist/` — готовый статический сайт, аудио, шрифты и QR-библиотеки.
- `dist/player.js` — управление звуком и распознавание данных QR.
- `dist/app.js` — интерфейс, камера и распознавание фото QR.
- `server.mjs` — HTTP-сервер с поддержкой диапазонов аудио.
- `tests/` — автоматические проверки.

Первый запуск звука требует нажатия ▶. При недоступной камере можно снять фото QR или ввести номер точки. Приложение использует Wake Lock, где он поддерживается; воспроизведение при блокировке телефона зависит от ОС и браузера. Живую камеру на физическом iPhone/Android нужно проверить перед выставкой.
