# Проверка платформы — 19 октября 2026

- 18 автоматических проверок пройдены: выбор точек, стартовый и компактные QR, чужие коды, фон, пауза/продолжение, конец рассказа, быстрые переключения, устаревшие события, отложенный запуск, блокировка автозвука и повтор после ошибки.
- В браузере через штатный выбор фото проверены стартовый QR и четыре точки. Проверен повёрнутый QR с большими полями. Чужой QR отклоняется без перехода на другой сайт.
- В браузере подтверждены реальная длительность записи, прогресс, сохранение позиции при паузе/продолжении и переход к непрерывному фону после окончания рассказа.
- Все четыре аудиофайла декодированы: 23,9 / 18,8 / 17,4 / 19,2 секунды. Средняя громкость −18…−19 dB. Метаданные перенесены в начало M4A для быстрого старта.
- Сервер: 13 ресурсов доступны, MIME audio/mp4, HEAD без тела, HTTP 206 для начала и конца файла, HTTP 416 для недопустимого диапазона, HTTP 404 для отсутствующего файла и HTTP 405 для неподдерживаемого метода.
- На 320×568, 390×844 и 430×932 основной экран помещается целиком; нет горизонтальной прокрутки; кнопка сканера видна.
- Исправлена очистка камеры при закрытии и отложенном разрешении доступа. Нативная камера для фото не конфликтует с живым видеосканером. При уходе в камеру телефона диалог с выбранным фото сохраняется.

Границы проверки: нет физического iPhone/Android для живого видеосканирования; временный HTTPS-туннель использовался только для проверки и не входит в репозиторий. Сквозное распознавание фото и фактическое воспроизведение проверены в браузере Codex, а не в мобильном Safari/Chrome.
